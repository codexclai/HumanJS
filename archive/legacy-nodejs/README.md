# Legacy Node.js project material

This directory is reserved for reviewed, explicitly archived material from the former Node.js implementation.

The complete legacy source tree has not yet been migrated into this directory. Its original upload filename, SHA-256, size, inventory, and migration status are recorded in docs/operations/LEGACY-SNAPSHOT-RECEIPT.md. Do not assume a complete source backup is already present in GitHub.

When archival imports are performed, preserve their original internal paths under a dated snapshot directory, include provenance and an inventory, exclude secrets and unlicensed material, and ensure that no active workflow, build, package, or runtime imports them. Do not place the old implementation in active source paths or port it line-by-line.

Reviewed scientific references and reproducible findings that remain useful should be promoted into research/ or experiments/ with source provenance and an explicit re-evaluation record.
